# MET Cloud Layers

Layered cloud cover (low/mid/high + fog) from MET Norway's free
Locationforecast API, with derived **sky transmittance** and
**PV-weighted sky quality** sensors for solar/battery automation.

- No API key required — just a location.
- 11 sensors incl. a 48 h hourly forecast attribute for Node-RED/templates.
- Tunable per-layer attenuation weights in the options.
- TOS-compliant: identifying User-Agent, If-Modified-Since caching, 4-decimal coordinates.

Weather data © Norwegian Meteorological Institute, CC BY 4.0.
